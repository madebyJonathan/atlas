# Atlas Construction Co. — Website Design

A website design project for **Atlas Construction Co.**, a licensed contractor serving West Los Angeles homeowners since 2014.

## Project Overview

This repo contains the full website design for Atlas Construction Co., built in [Pencil](https://pencil.design) (`.pen` format) along with supporting assets and content planning documents.

## Sections

The website is a single-page design consisting of:

- **Hero** — Full-bleed image header with navigation overlay
- **Who We Are** — Brand intro with stats and team image
- **Selected Works** — Three-column project photo grid
- **Our Expertise** — Tabbed service areas with imagery
- **Our Process** — Dark-themed step-by-step process section
- **Testimonials** — Centered quote with client avatar
- **Contact** — Dark two-column form section
- **Footer** — Links, credits, and legal

## Design Details

- **Canvas width:** 1440px
- **Typography:** Perfectly Nineties (headings), JetBrains Mono (body)
- **Color palette:** White `#FFFFFF`, Dark `#2c2c2c`, Charcoal `#1a1a1a`, Accent text `#555555`
